Quick Start Guide
Kinspace Tablet Local

Let's get focused

A simple tablet for routines, to-dos, timers, reminders, achievements, and family progress.

Start with setup, then add your daily routines.
1. First-Time Setup

Get started in five easy steps

  1. Turn on the tablet and open Kinspace.
  2. Enter a household name.
  3. Add each family member by name.
  4. Optionally enter a birthdate.
  5. Tap Finish local setup.

Good to know: initial setup adds everyone as a Member. You can manage people later in Settings.

2. Daily Use

Use Home for the everyday routine

Home

See today's tasks, progress, and sections like Morning and Afternoon.

Today

Jump back to the current day anytime with the Today button.

Add

Use the floating + button to create a new task.

Complete

Tap a task to mark it done and update daily progress.

Helpful feature: when typing a task title, Kinspace suggests matching past task names so you can reuse them quickly.

3. Build Better Routines

Create tasks that are easy to keep using

  • Tasks can be added or edited on any selected day.
  • Repeat options include Once, Daily, Weekdays, Weekends, Weekly, Monthly, Yearly, and Custom.
  • Use timers for tasks that benefit from focus support.
  • Browse earlier or later days with the date controls on Home.

Best first step: create your main recurring routines first, then fine-tune reminders later.

4. Settings That Matter

Caregiver controls in one place

  • Set one tablet-wide 5-digit passcode for Settings.
  • Manage family members and choose who the tablet opens to first.
  • Adjust reminders for Morning, Afternoon, Evening, and Bedtime.
  • Set category end times separately for each part of the day.
  • Use Kiosk Help if this will be a dedicated tablet.

Reminder tip: category alarms are separate from task timers, so you can tune daily routine reminders without changing the task itself.

5. Protect Your Data

Use backups and reports regularly

  • Create a local backup after major changes.
  • Use Restore if you ever need to recover the tablet.
  • Open Reports to review each family member's progress.
  • Export summaries with Quick Export, Save TXT, or Save CSV.

Recommended weekly habit: review reports once a week, then create a fresh backup.

Need help later? Open Settings on the tablet.
