# Kinspace Tablet Local User Guide

This guide walks through the core screens in **Kinspace Tablet Local** and is based on the current local-only tablet build.

Screenshots in this guide were captured from the emulator while walking the app flow.

## Screen Map

The main navigation is simple:

- **Home**: today’s tasks and daily progress
- **Achievements**: streaks, badges, and puzzle progress
- **Settings**: tablet controls, reminders, backups, reports, and family management

## What This Tablet App Does

Kinspace Tablet Local is a family organization hub designed to run directly on the device. It keeps household data on the tablet and is built for:

- daily routines
- to-do tracking
- timers and focus sessions
- achievements and streaks
- caregiver-friendly reports
- local backups

## First Launch

When the app opens for the first time, you will land on the setup screen.

![Initial setup screen](guide_setup_start.png)

### Setup Steps

1. Enter a **Household name**.
2. In **Add Family Member**, enter a name for each person who will use the tablet.
3. Optionally enter a birthdate in `YYYY-MM-DD` format.
4. Tap **Add member** for each person.
5. Tap **Finish local setup** when at least one person has been added.

Important notes:

- Everyone added during initial setup is created as a **Member**.
- You can manage family members later from **Settings**.

## Home Screen

After setup, the tablet opens to the main Home screen for the current member.

![Home screen](kinspace_splash_check.png)

### What You See on Home

- A greeting with the current member name
- Navigation icons in the top area for:
  - member switching
  - calendar/date actions
  - refresh
- The current day and date
- A **Today** button to quickly return to the current day
- Progress for the day
- To-do groups such as **Morning**, **Afternoon**, and other routine sections
- A floating **+** button to add a new to-do
- Bottom navigation for:
  - **Home**
  - **Achievements**
  - **Settings**

Tips:

- Use the **back arrow** near the date to move away from today.
- Use **Today** at any time to jump back to the current day.
- The date text will shrink automatically if needed so the **Today** button stays readable.

## Daily Use

### Completing a To-Do

1. Find the task in its category section.
2. Tap the completion control for the task.
3. The daily progress area updates as tasks are completed.

### Adding a To-Do

1. Tap the floating **+** button on Home.
2. Enter the to-do title.
3. As you type, Kinspace suggests distinct past task titles that match what you have entered.
4. Fill in the rest of the task details.
5. Save the task.

### Editing a To-Do

You can edit or manage to-dos on **any selected day**, not just today.

Typical flow:

1. Navigate to the day you want to view.
2. Open the task’s management controls.
3. Edit the task details.
4. Save changes.

### Reusing Past To-Do Titles

When entering a title for a new to-do:

1. Start typing in the title field.
2. Kinspace will show matching titles from distinct past to-dos.
3. Tap a suggestion to fill the title quickly.

This helps keep task naming consistent across days and members.

### Repeat Frequency Options

When creating or editing a to-do, repeat options include:

- Once
- Daily
- Weekdays
- Weekends
- Weekly
- Monthly
- Yearly
- Custom

## Achievements

Use the bottom navigation bar to open **Achievements**.

This area shows:

- progress and streak-based rewards
- puzzle progress
- member-specific achievement history

## Settings

Open **Settings** from the bottom navigation bar.

Settings is where you manage the tablet itself, not just the current day.

Main tasks people usually handle in Settings:

- protect the tablet with a passcode
- manage family members
- change reminder behavior
- review reports
- create or restore backups
- review kiosk setup guidance

### Settings Areas

Depending on your current configuration, Settings includes sections such as:

- **Settings Passcode**
- **Family**
- **Local Backup**
- **Kiosk Help**
- **Category Reminders**
- **Reporting**

### Tablet-Wide Passcode

If you set a Settings passcode:

- it applies across the whole tablet
- it is shared for all members
- it is not configured separately per person

### Category Reminders

Category reminders can be configured in Settings.

You can control:

- whether category reminders are enabled
- per-category reminder behavior
- reminder timing
- category end times

Each category can be tuned separately, so you can set different reminder behavior for:

- Morning
- Afternoon
- Evening
- Bedtime

## Reports

From **Settings**, tap **Open Reports**.

Reports are member-based. Start by selecting the family member you want to review.

Reports include:

- completed to-dos
- current streak
- best streak
- average completion time
- paused time percent
- restarted session percent
- canceled session percent
- stopped-before-end percent
- completed-after-end percent
- best success window
- completed to-dos by category
- timer session outcomes
- recent trends
- suggested next moves

### Export Options

Reports supports:

- **Quick Export**
- **Save TXT**
- **Save CSV**

There is also a **Back to Settings** button at the top of the Reports screen.

## Family Management

From **Settings**, open **Manage Family Members** to:

- add more members after initial setup
- remove members
- update family member details
- change who the tablet opens for by default

Initial setup creates everyone as a **Member**. Later family management is where you make broader household changes.

## Local Backup

From **Settings**, use **Local Backup** to protect the tablet’s data.

Available actions include:

- **Create Backup**
- **Refresh**
- **Import Backup File**
- **Restore**
- **Export**
- **Delete**
- **Delete All Backups**

Use backups regularly, especially before changing kiosk settings or moving to a different device.

## Kiosk Basics

Kinspace Tablet Local is designed to work well as a dedicated household tablet app.

From **Settings > Kiosk Help**, you can review the recommended setup:

1. Install Kinspace on the tablet
2. Set Kinspace as the Home app when Android asks
3. Protect Settings with a passcode
4. Create local backups regularly

If accessibility services such as TalkBack are needed, use the **Accessibility Settings** shortcut in Settings before returning the device to kiosk use.

## Good First Setup Checklist

After installing the app, we recommend this order:

1. Complete initial setup
2. Add all family members
3. Set the tablet-wide Settings passcode
4. Review category reminders
5. Add the main recurring to-dos
6. Create the first local backup
7. Set Kinspace as the Home app if this will be a dedicated family tablet

## Suggested Daily Routine For Families

Here’s a simple way to use the tablet day to day:

1. Open the tablet to the active family member’s Home screen
2. Review the **Morning** section together
3. Start timers only for tasks that benefit from focus support
4. Check tasks off as they are completed
5. Use **Today** whenever you want to quickly reset the view back to the current day
6. Review **Reports** weekly rather than constantly
7. Create a fresh **Local Backup** after major household changes

## Troubleshooting

### I cannot change Settings

- Check whether a Settings passcode is enabled
- Enter the 5-digit passcode to unlock Settings

### I want to switch to a different person

- Open **Settings**
- Tap **Switch Member**

### I need to get back to today

- Use the **Today** button on the Home screen

### I want to recover from a device issue

- Open **Settings**
- Use **Local Backup** to restore the latest backup if one is available
