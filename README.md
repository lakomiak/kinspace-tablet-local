# ADHD Focus App

A specialized Android tablet interface designed for family members with ADHD. This app provides a distraction-free, visually engaging task management experience that syncs with the calendar-cloud infrastructure.

## Features

- **Daily Focus View**: Simplified interface showing only today's tasks
- **High-Contrast Visual Cues**: Clear indicators for task status (incomplete, in-progress, completed)
- **Timers with Feedback**: Visual and audio feedback for task duration tracking
- **Gamification**: Badges, streaks, and efficiency metrics for motivation
- **Affirmations**: Positive reinforcement on task completion
- **Cloud Sync**: Real-time synchronization with calendar-cloud
- **Offline Support**: Full functionality without internet connectivity
- **Family Integration**: Real-time updates from family members
